<th>加工工艺</th>
<th>定义</th>
<th>常用名称/修饰语</th>
</tr>
<tr>
<td>8</td>
<td>发酵<br>Fermentation</td>
<td>应用酵母、霉菌或细菌在受控制的有氧或厌氧条件下，增殖菌体、分解底物或形成特定代谢产物的过程。</td>
<td>发酵</td>
</tr>
<tr>
<td>9</td>
<td>粉碎<br>Crushing</td>
<td>通过撞击、剪切、磨削等机械作用，使物料颗粒变小。</td>
<td>粉碎</td>
</tr>
<tr>
<td>10</td>
<td>分选<br>Fractionation</td>
<td>通过过筛或气流处理将物料中不同容积、不同粒径的组分分离。</td>
<td>分选</td>
</tr>
<tr>
<td>11</td>
<td>风选<br>Aspiration</td>
<td>利用物料之间或物料与杂质之间悬浮速度的差别，用空气（风力）对物料进行分级或去除杂质的过程。</td>
<td>风选</td>
</tr>
<tr>
<td>12</td>
<td>干燥<br>Drying</td>
<td>去除物料中的水分或者其他挥发性成分。</td>
<td>干燥</td>
</tr>
<tr>
<td>13</td>
<td>谷物发芽<br>Malting</td>
<td>使谷物发芽，激活其自身能够使淀粉降解为可发酵碳水化合物，使蛋白质降解为氨基酸和小肽的酶。</td>
<td>发芽</td>
</tr>
<tr>
<td>14</td>
<td>过滤<br>Filtration</td>
<td>通过多孔介质或膜分离固液混合物。</td>
<td>过滤</td>
</tr>
<tr>
<td>15</td>
<td>烘烤<br>Roasting/Toasting</td>
<td>物料置于火、热气、电或微波等加热环境中，进行烘焙、干燥，以提高消化率、加深颜色或减少天然抗营养因子。</td>
<td>烘烤</td>
</tr>
<tr>
<td>16</td>
<td>混合<br>Mixing</td>
<td>利用机械力、压缩空气或超声波，搅动、拌和物料，使之分布均匀，强化热交换的过程。</td>
<td>混合/搅拌</td>
</tr>
<tr>
<td>17</td>
<td>挤压膨化<br>Extrusion/Extruding</td>
<td>物料经螺旋杆推进、增压、增温处理后挤出模孔，使其骤然降压膨化，制成特定形状的产品。</td>
<td>膨化</td>
</tr>
<tr>
<td>18</td>
<td>挤压膨胀<br>Expansion/Expanding</td>
<td>物料经螺旋杆增压挤出模头，使其适度降压而膨大，制成不规则的形状。通常，挤压膨胀的压力和温度低于挤压膨化。</td>
<td>膨胀</td>
</tr>
<tr>
<td>19</td>
<td>加热<br>Heating</td>
<td>通过提高温度，加压或不加压，对物料进行处理的方法。</td>
<td>热处理</td>
</tr>
<tr>
<td>20</td>
<td>碱化<br>Basification</td>
<td>向物料中添加碱性物质使物料由酸性变为碱性（提高pH值）的过程。</td>
<td>碱化</td>
</tr>
<tr>
<td>21</td>
<td>胶凝<br>Gelling</td>
<td>形成不同凝胶强度的固体凝胶物质的过程（使用或不使用凝胶剂）。</td>
<td>凝胶</td>
</tr>
<tr>
<td>22</td>
<td>结晶<br>Crystallization</td>
<td>物质从溶液中形成固态晶体并与液体分离的分离纯化过程。</td>
<td>结晶</td>
</tr>
<tr>
<td>23</td>
<td>浸泡<br>Soaking/Steeping</td>
<td>在一定条件下，对物料（通常是对籽粒）进行湿润和软化的过程，以减少蒸煮时间，或有利于去除种皮，或加快水分吸收以促进发芽进程，或降低天然抗营养因子的浓度。</td>
<td>浸泡</td>
</tr>
<tr>
<td>24</td>
<td>浸提/抽提<br>Extraction</td>
<td>利用有机溶剂从物料中提取油脂，或利用水和水性溶剂提取糖或水溶性物质的过程。</td>
<td>浸提/抽提</td>
</tr>
</table>

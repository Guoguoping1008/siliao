### C 类 · 可以开工,但还没做

#### #4 禁用规则抽取(`rule_type='prohibition'`)

现状(实测):**领域模型已支持 4 种 rule_type**(`limit` / `prohibition` / `condition` / `combination`),
判定器也已实现「禁用优先 → 无条件拒绝」分支 —— **但抽取器只产出 `limit`**:

```python
# build/export/extract_compliance_rules.py
"rule_type": "limit",   # ← 只有这一种
```

生产 `status=prohibited` 现在**永远不可能返回**。

**数据可得性已实测**:语料里 **39 个文件**含「禁用」相关条款,包括
《食品动物中禁止使用的药品和其他化合物清单》等。

⚠️ **抽取必须剔除假阳性** —— 实测样例:

> 「不得在饲料生产过程中进行维修、焊接、气割等作业。」← **这条不是禁用物质!**

这是生产操作禁令,不是物质禁用。所以 `prohibition` 也必须走 `review_status` 闸门。

**工作量**:2-3 天(抽取器 + 假阳性识别 + 单测 + 校核清单)

#### #5 组合/条件规则抽取

领域模型支持 `combination` / `condition`,**但一条都没抽出来**。

实测语料里有 4 种待覆盖的写法:

| # | 原文形态 | 示例 | 难点 |
|---|---|---|---|
| 1 | 多动物并列 + 阶段 | `罗非鱼、鲶鱼—鱼苗300mg/kg—鱼种200mg/kg` | 一个动物对应**两个阶段值** |
| 2 | 括号内嵌套 | `猪30~50mg/kg(乳猪300~500mg/kg)` | 括号是**例外**不是主值 |
| 3 | 多物质共用一条 | `同时使用时,在配合饲料中的总量不得超过150mg/kg` | 约束对象是**组合** |
| 4 | 使用条件 | 「适用于育肥期」「不得与…同时使用」 | 需要抽条件文本 |

当前抽取器用 `is_combination()` **跳过**了第 3 种(统计计数 `combination_skipped`),
没有把它建成独立规则类型。

**工作量**:1-2 天

现状:`GET /api/calendar` → **404**。

**能做的部分**:标准正文常写「本标准自 XXXX 年 XX 月 XX 日起实施,代替 XXXX 版」——
**可从语料正则抽取**。语料里有 `04标准及标准目录/` 下的标准文本。

⚠️ **明确不能做的**:换证/年检提醒 —— 那是**企业侧证件到期日**,语料里没有。

#### #10 版本追溯 + 领域标记

**版本追溯**:生产实测 `GET /api/documents/:id/status` → **404**。
`documents` 表结构实测**没有** `status` / `supersedes_doc_id` 字段,`articles` 也没有 `version_snapshot`。

**即使加了字段,历史仍为空** —— 语料是「2026 版汇编」,只有现行版本:

| 来源 | 可得性 |
|---|---|
| 现行法规的修订说明章节 | 🟡 语料里可能有 |
| 历史版本 PDF | ❌ 需采购/爬取(农业农村部不提供结构化历史) |
| 变更时间线 | ❌ 需 ⑧ 监测上下文 |

**结论**:第一期只能做到「标注当前版本 + 标注被取代关系」,真正回溯要等 ⑧ 落地后积累。

**领域标记**:`documents` 表**无 `domain` 字段**,现在只能靠目录名硬编码。
生产实测 `GET /api/documents?domain=feed` → **200 但参数被忽略**(返回全部文档,
说明路由层根本没读这个 query 参数)。

加 `domain TEXT DEFAULT 'feed'`(`feed` / `veterinary` / `pet_food` / `general`)后,
支持「只查兽药法规」「排除通用法规」—— 语料里 32 份相关法律法规文件含兽药法规,
现在没法过滤。

**工作量**:2-3 天(两者一起做,因为都要改 schema)

## 三、明确不做(数据源不存在,不是没排期)

| 项 | 原因 |
|---|---|
| **企业资质审查** | 语料里「生产许可证」命中 88 个文件,但那是**许可证的条款**(规定怎么办理),不是**企业的实际证件数据**。语料是法规,不是证件库。 |
| **抽检结果「同类产品风险提示」** | 国家饲料质量抽检结果由农业农村部以公告(PDF)形式发布,**无 API**;粒度是「产品批次 + 检验结论」,**没有企业配方数据** —— 无法做「同类产品」关联。可降级为「抽检公告聚合检索」,语义不同,需在产品文档写清。 |
| **合规日历 · 换证/年检提醒** | 需企业侧证件到期日,语料里没有。 |
| **真正的历史版本回溯** | 农业农村部不提供结构化历史版本,只能积累上线后的变更。 |
| **跨模块 Planner(复杂问题拆解)** | 法规问答大多是单跳检索。真正的复杂场景(配方审查)走确定性接口,**不该走 LLM Planner**。低频高价值,等真实提问日志出来再定。 |
| **「物质 → 可用替代品」映射** | 这是**新产品审定**的知识,语料是法规不是审定结论库。v1 只给「允许区间」,替代建议不承诺。 |

# 目标
识别文本中所有命名实体,以及实体间的有意义关系。仅抽取在文本中**明确出现**的实体;不要推测未出现的实体。

# 实体类别(优先级从高到低)
1. 法律法规(LAW): "饲料和饲料添加剂管理条例"、"农产品质量安全法"等
2. 主管部门(AGENCY): "农业农村部"、"县级以上人民政府农业农村主管部门"等
3. 行政相对人(PARTY): "饲料生产企业"、"经营者"、"申请人"等
4. 许可与证书(CERTIFICATE): "审定证书"、"经营许可证书"、"饲料添加剂审定证书"等
5. 文件(DOCUMENT): "申请书"、"质量检验报告"、"安全性评价报告"等
6. 行政行为(ACTION): "审批"、"处罚"、"监督检查"、"抽样检验"等
7. 法律责任(PENALTY): "罚款"、"没收违法所得"、"责令停止生产"等
8. 物质与产品(SUBSTANCE): "饲料添加剂"、"单一饲料"、"配合饲料"等
9. 地点(LOCATION): 仅国家级/省级行政区
10. 概念(CONCEPT): "饲料质量安全"、"审定制度"等行业术语

# 关系类型
- 颁布(LAW, AGENCY): 某主体颁布了某法规
- 适用(LAW, PARTY): 某法规适用于某主体
- 监管(AGENCY, PARTY): 某主管部门监管某主体
- 规定(LAW, ACTION): 某法规规定了某行政行为
- 要求(LAW, CERTIFICATE): 某法规要求取得某证书
- 处罚(Law, PENALTY): 某法规设定了某处罚
- 定义(Law, CONCEPT): 某法规定义了某概念
- 涉及(SUBSTANCE, LAW): 某物质被某法规监管

# 输出格式
返回标准 JSON 数组,每个元素形如:
{"entity": "...", "type": "...", "description": "..."}

关系单独成数组:
{"source": "...", "target": "...", "relationship": "...", "description": "..."}

只输出 JSON,不要附加解释。

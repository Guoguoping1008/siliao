## 口径说明

```
引用准确率 = 答案中 valid:true 的引用数 / 答案中全部引用数
```

- `valid` 由 `citation-validator.service.ts` 判定：引用号 N 必须对应检索证据的第 N 条；N 超出证据范围 → `valid: false`（LLM 编造）
- **无引用**不计入准确率分母 —— 它是「没有依据」，单独用占比阈值管
- 「答案引用标记与 citations 同步」查的是校验器与答案是否脱节（答案里写了 `[3]` 但 citations 里没有 → Worker 侧问题）
